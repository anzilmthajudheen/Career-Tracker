
# Career Tracker Platform

A modern Career & Government Opportunity Tracking Platform built using React, Vite, and Tailwind CSS.

## Features

### Career Management
- Company tracking
- Application status management
- Search and filter applications
- Career page redirection
- Interview tracking
- Application analytics

### Government & PSU Preparation
- Kerala PSC tracking
- SSC, UPSC, RRB, IBPS sections
- PSU opportunities
- Upcoming deadlines
- Notification system

### Analytics Dashboard
- Application statistics
- Pie charts
- Bar charts
- Selection/rejection tracking

### MCQ Test System
- Technical MCQs
- Government exam MCQs
- Score calculation
- Interactive UI

### Mock Interview System
- HR interview questions
- Technical interview preparation
- Answer recording system

## Tech Stack

- React.js
- Vite
- Tailwind CSS
- React Router DOM
- Chart.js
- React Icons

## Installation

Clone repository:

```bash
git clone https://github.com/anzilmthajudheen/Career-Tracker.git
```

Go to project folder:

```bash
cd Career-Tracker
```

Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm run dev
```

## Deployment

This project is deployed using Vercel.
